# B2B Закупка неликвидов и б/у оборудования

Веб-приложение для приёма коммерческих предложений по выкупу складских остатков, неликвидов и бывшего в употреблении промышленного оборудования и материалов.

## Стек технологий

- **React 19** + **TypeScript 5** (`strict`)
- **Vite** + **Tailwind CSS v4** (`@tailwindcss/vite`)
- **Lucide React** + векторные технические схемы SVG (без внешних растровых изображений)

## Локальный запуск и сборка

Требуется **Node.js 20+** (рекомендуется **Node.js 22**).

```bash
# Установка зависимостей
npm install

# Режим разработки (горячая перезагрузка)
npm run dev

# Строгая проверка типов TypeScript
npm run typecheck

# Финальная сборка в каталог dist/
npm run build

# Локальный предпросмотр собранной версии
npm run preview
```

## Деплой на Netlify

В корне проекта настроен файл `netlify.toml`:

- **Build command:** `npm run build`
- **Publish directory:** `dist`
- **Node.js:** `NODE_VERSION = "22"`
- **SPA Redirects:** правило `/* -> /index.html (200)` для корректной маршрутизации разделов (`#main`, `#terms`, `#contacts`, `#legal`, `#admin`) и параметров строки запроса (`?edit=1`).

Для публикации достаточно подключить репозиторий к Netlify или перетащить собранную папку `dist` в панель деплоя.

## Визуальный редактор контента (`/#admin`, `/?edit=1`, `Alt + E`)

Для владельца сайта предусмотрен встроенный визуальный режим редактирования без серверной базы данных (все данные хранятся прямо в коде репозитория в файле `src/config/siteConfig.ts`):

1. **Как открыть панель редактора (три способа):**
   - Перейдите по адресу сайта с хешем `/#admin` или параметром `/?edit=1`;
   - Выполните **тройной клик** по названию **«Отдел закупки»** в шапке сайта;
   - Нажмите сочетание клавиш **`Alt + E`**.
2. **Что можно изменить с мгновенным предпросмотром:**
   - **Телефон** (ссылки `tel:`, Telegram и WhatsApp пересчитываются автоматически);
   - **Заголовок** на главном экране (`Покупаем неликвиды, складские остатки и б/у промышленное оборудование`);
   - **Список категорий** каталога: редактирование названия и примера-подсказки, удаление позиций и добавление новых через кнопку «+ Добавить категорию».
3. **Как сохранить изменения навсегда:**
   - Нажмите кнопку **«Скопировать готовый конфиг для GitHub»** в нижней части панели редактора — в буфер обмена скопируется полный валидный код TypeScript-модуля;
   - Замените содержимое файла `src/config/siteConfig.ts` скопированным кодом и выполните коммит в Git — Netlify автоматически пересоберёт обновлённый сайт.
